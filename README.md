# LLM Output Gate

A deterministic output handling gate for Large Language Models (LLMs), designed to mitigate security risks associated with untrusted LLM outputs (addressing [OWASP LLM05 - Improper Output Handling](https://owasp.org/www-project-top-10-for-large-language-model-applications/assets/PDF/OWASP-Top-10-for-LLMs-2023-v1_1.pdf)).

This service provides an API endpoint to sanitize and validate outputs before they are processed by downstream applications or rendered to users. It supports different context channels such as HTML, Markdown, URL, SQL, and Shell commands, applying specific validation rules for each to prevent cross-site scripting (XSS), SQL injection, command injection, and data exfiltration.

## Features

- **Multi-channel Validation:** Context-aware checks for `html`, `markdown`, `url`, `sql`, and `shell` outputs.
- **Deep Decoding:** Mitigates obfuscation bypasses by recursively decoding percentage encodings, HTML entities, and Unicode escapes before evaluation.
- **URL Safety Analysis:** Detects dangerous URI schemes (e.g., `javascript:`, `vbscript:`) and prevents data exfiltration by enforcing an allowed list of domains.
- **Resilient API:** Robust JSON parsing and error handling to always return a deterministic, well-formed verdict.

## API Usage

### `POST /sanitize-output`

Evaluates LLM output against a specified context channel.

**Request Body (JSON):**

```json
{
  "channel": "html",
  "output": "<a href=\"https://example.com\">Click here</a>"
}
```

- `channel`: One of `html`, `markdown`, `url`, `sql`, `shell`.
- `output`: The raw string generated by the LLM (max length: 20,000 characters).

**Response (JSON):**

```json
{
  "safe": true,
  "reason": "SAFE"
}
```

If the payload is deemed unsafe, `safe` will be `false` and `reason` will indicate the specific violation (e.g., `SCRIPT_TAG`, `DANGEROUS_SCHEME`, `EXTERNAL_EXFIL`, `SQL_METACHAR`, `SHELL_METACHAR`, `ENCODED_PAYLOAD`).

## Configuration

You can customize the `ALLOWED_HOSTS` array in `server.js` to define the authorized domains for absolute URLs extracted from HTML and Markdown outputs, mitigating potential external exfiltration risks.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server:
   ```bash
   npm start
   ```

The service will run on port `3000` (or `$PORT` if configured).
